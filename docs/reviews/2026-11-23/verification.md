## Not covered by any verdict

- README 'sample-free cell state' example and the sample_blind donor-leakage argument: no verdict covers it. Review advice is to correct the README and test donor predictability within cell type.
- Penalized-objective claims: get_elbo cannot rank prior scales or architectures. No verdict covers this documentation point.
- Monitoring item, partial: the extra claims are untested. They are the global embedding penalty using the registered cell count, protein-likelihood warm-up entering with the KL weight, and the terminal KL weight below one on large runs.
- Invariance item, second half: no verdict covers the claim that the inherited adversary can turn on for all-zero panel entries and acts on z, including the donor residual.
- Mixture-mean identity efficiency*E[B]*[1+(1-pi)(f-1)] and the ambient c*a term: no verdict re-derived it. Only the existing test is cited by the review.
- Conditional non-identifiability of c versus B and f (c'=c+delta, B'=B-delta*a, f' preserved): no verdict checked the algebra numerically.
- Isotype-mode nuisance encoder reading total ADT counts, so target expression can enter it: no verdict covers it.
- Upstream normalized protein expression includes the full foreground rate with ambient signal, and the review asks for a consistent public native-component entry point: only partly touched by the isotype verdict.
- Experiments headline: median RMSE on log1p native counts fell 0.599 to 0.503 across all four pairs, and the 'other 18 markers improved in only one pair' claim. The experiments skeptic only reran one fit (seed 17) for induced markers. The RMSE and 18-marker claims, the seed-29 data and the 'eight fits' were not reproduced.
- Earlier-simulation claims (donor-pooling 0.043 vs MrTotalVI 0.232 vs stock totalVI 0.457; longer training helps): no verdict. They are labelled archived runs on an older commit.
- Paired-DA fixture (mean donor log ratio -0.400 vs grouped +0.680) and the kNN-versus-kernel pooling and donor-weighting argument: no verdict.
- Package-tested-behaviour claims: the 418 passed, 1 skipped suite result, the 26 passed ambient tests at 37bd399, and 'ambient-isotype save/load returns matching native predictions'. None was rerun.
- Review proposal to freeze the training split before estimating empirical masks and weighting denominators (not only the protein prior), with 'supplied experimental panel masks distinct': only the protein background prior was checked. Empirical missingness masks and weighting denominators are unchecked.
- Review's 'test on the newest scvi-tools version claimed as supported' for the inherited API combinations: no newer version was tested.
- Sample_blind fixture claim about the DA 'omit_original_sample' group construction (one reference sample in its own group, two in the other) was not independently checked.

## Critic spot checks

- cell-selection (a), bool mask with sample= in get_aggregated_posterior: re-read src/mrtotalvi/_stats.py L51-54 and L117-123 on HEAD 0030c3d. _as_indices only does np.asarray, so a bool mask reaches np.intersect1d as 0/1. The finding holds by source. My scripted rerun (cell-selection/g.py) did not finish: the host was heavily loaded and it timed out. I did not independently reproduce the numbers.
- feature-identity (a), no RNA name check: grep for var_names in src/mrtotalvi finds no check in _model.py. The only var_names uses are the multi-file datamodule, one counterfactual use (_counterfactual.py L1323) and the manager getter. _check_protein_names (_model.py L2037-2060) covers protein uns only. Source supports the verdict. The 0.3385 latent diff was not rerun, same timeout.
- feature-identity (b), protein validator bypassed: authoritative_protein_names is imported only in _datamodule.py (L53, L130). _model.py never calls it, so setup_anndata cannot reach it. Source supports the verdict. Note that _check_protein_names' docstring says scvi itself compares DataFrame column names on transfer. The verdict's claim that a DataFrame-only permutation passes at query time was not tested.
